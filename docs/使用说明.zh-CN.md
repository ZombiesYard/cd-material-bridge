# CD Material Bridge 0.1.1 — 使用说明

## 用途

该插件为配套服装的特定贴图启用 AlphaTest 登记，使贴图中的透明区域能够用于蕾丝、孔洞等裁切效果。它通过规则匹配纹理，只处理路径、分辨率、格式、mip 和像素哈希全部符合的资源。

插件不提供服装、贴图或物理，也不改变金属度、粗糙度和模型形状。AlphaTest 是镂空裁切，不能单独实现渐变半透明、折射或全部原游戏材质效果。

## 安装

运行环境为 Windows x64。需要支持本插件文件重定向接口的 Ultimate ASI Loader；加载器不包含在独立 ASI 产物中。运行插件不需要 Python 或 Visual Studio。

1. 完全退出游戏。
2. 使用 DMM 安装并启用配套服装，按正常流程执行 Mount Mods。
3. 如服装提供 DMM 格式的插件 ZIP，在 ASI Mods 中安装并启用 CD Material Bridge，并按 DMM 提示配置兼容加载器。
4. 确认该服装的 INI 规则也已安装。单独的 ASI 不包含任何服装规则；没有规则时不会修正登记。
5. 启动游戏。规则或插件更新后需要完全退出并重新启动。

独立源码构建得到的是裸 ASI，不是 DMM 安装 ZIP。手动安装的常见布局如下，加载器另行安装：

```text
Crimson Desert/
  bin64/
    CDMaterialBridge.asi
    CDMaterialBridge/
      rules/
        ExampleOutfit.ini
```

多套服装共用一份 `CDMaterialBridge.asi`，保留各自需要的规则。不要把插件重命名后重复加载。对于同一路径的贴图冲突，插件不会合并两份不同内容。

## 工作方式与数据

游戏启动时，插件读取当前挂载表、纹理登记和规则涉及的贴图。只有匹配成功的条目才开启 Alpha 最低位；共用登记头会为目标单独复制，避免修改其他纹理。

修正表保存到 `bin64/CDMaterialBridge/cache/`，再由加载器将当前进程的相关文件读取重定向到该副本。原始游戏档案和登记文件不会被覆盖。插件还写入 `bin64/CDMaterialBridge/CDMaterialBridge.log`，记录匹配、跳过和重定向结果。

请保留配套贴图的原尺寸与编码。缩图、重新压缩或替换任何 mip 都可能改变像素哈希，使规则停止匹配；应由服装维护者为最终文件更新规则。

## 排查

| 日志 | 含义与处理 |
| --- | --- |
| `ASSET_VERIFIED` | 实际生效的贴图通过身份检查；不代表最终画面已经验证 |
| `ALPHA_ENABLED` | 修正副本中的目标 Alpha 标志已启用 |
| `REDIRECT_READY` | 重定向注册及读回成功；仍需在游戏内查看材质 |
| `ALREADY_ENABLED` | 原登记已启用 Alpha，无需重复修改 |
| `NO_REDIRECT` | 没有需要修正的有效条目；结合前面的日志判断原因 |
| `ASSET_MISSING` / `ASSET_SKIPPED` | 资源缺失、被覆盖、尺寸或像素不同，或存储方式不支持 |
| `RULE_FILE_SKIPPED` | INI 不符合规则格式；该文件被跳过 |
| `REGISTRY_SKIPPED` | 目标纹理登记未满足预期条件 |
| `INACTIVE` | 初始化失败；日志后文提供原因 |

若日志仅显示 `RULES 0`，检查规则是否部署到正确目录。没有日志时，先检查加载器和 ASI 是否启用、插件路径及目录写入权限。

## 停用与兼容性

关闭游戏后停用插件，再重新启动，即可停止本插件提供的重定向。游戏关闭时可以删除插件缓存。插件停用不会撤销其他工具对原始文件做过的编辑。

如果其他服装也依赖此插件，只移除不再使用的服装规则。游戏或加载器更新、同一登记文件被其他插件重定向，以及同一纹理路径被其他模组替换，都可能需要重新核对兼容性。请在游戏关闭时操作 Mount Mods。
